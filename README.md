## Projeto em destaque

### [BR-MANGUE Studio](https://github.com/oceanpep/br-mangue-studio)

Aplicação desktop em Python para simular e explorar a dinâmica espacial dos manguezais. O projeto reúne processamento de dados raster, cenários ambientais, mapas, séries temporais e saídas reprodutíveis. É desenvolvido no contexto de pesquisa do **GEOTAM**.

- [Código-fonte e documentação](https://github.com/oceanpep/br-mangue-studio)
- [Site do projeto e downloads](https://oceanpep.github.io/br-mangue-studio/)

I am a systems developer specializing in Data Analysis, an undergraduate Oceanography student, and an MSc student in Environmental Science and Technology at the Federal University of Maranhão (UFMA). My projects bring together software development, spatial analysis, and coastal research.

### Featured project

[**BR-MANGUE Studio**](https://github.com/oceanpep/br-mangue-studio) is a Python desktop application for simulating and exploring mangrove spatial dynamics. It brings together raster-data workflows, environmental scenarios, maps, time series, and reproducible outputs. The project is developed in the research environment of **GEOTAM**.
